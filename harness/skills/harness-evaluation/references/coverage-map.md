# 커버리지 맵 — 축 개편의 원장

**언제 읽나**: 축을 개편할 때만. 평가 회차마다 읽을 필요는 없다 — 리포트 표에 8축 행이 전부
있으면 이 맵은 이미 지켜진 것이다.

**규율 하나**: 개편 뒤 아래 두 표의 **행선지가 빈 항목이 생기면 개편은 미완성이다.**
세는 자리가 없으면 세지 않는다 — v3가 8·10축을 "판단 입력"으로 강등하자 v1 리포트에
네이티브 중복·모델 과잉 판정이 한 줄도 남지 않았다. 항목의 값어치 문제가 아니라 배치 문제였다.
