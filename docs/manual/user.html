auth 가드의 버그 한 줄

버그 수정 × Irreversible — 2 Phase + P6

  1. 진입 조건 4상태 판정 → 의도 명확·반경 파악됨 → 준비 단계 건너뜀
  2. P4 구현 시작. 편집 경로가 src/라 code-change · security · reversibility 카드가 로드됨
  3. 파일을 쓰려는 순간 security-check가 시크릿 패턴 검사 — 통과
  4. 클래스 판정: auth 경로 → Irreversible
  5. P5·P6 epcc-reviewer가 correctness·security·reversibility 세 관점으로 팬아웃
  6. 사용자 확인 요청 + 롤백 절차 작성
  7. 끝내려 하면 build-gate가 빌드/테스트 실행 여부를 확인

한 줄인데 가장 무겁습니다 — 줄 수가 아니라 경로가 정하니까요.

판정 방식 — 오탐을 막는 장치

  • 세그먼트 단위로 봅니다. ; && || 로 이어진 명령은 각각 따로 판정합니다.
  • 면제는 첫 토큰으로. 문자열 포함으로 면제했다가 doctor.sh …; psql -c "DROP TABLE"이 통째로 통과한 사고가 있었습니다.
  • 조사 명령은 통과. 시크릿 문자열이 들어 있어도 파일을 쓰지 않으면 막지 않습니다.
  • 판정 불가는 차단이 아닙니다. 입력을 파싱 못 하면 알리고 통과시킵니다.
