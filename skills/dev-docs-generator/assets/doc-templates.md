## 슬라이스

### 슬라이스 규칙

| 규칙 | 내용 |
| --- | --- |
| 수직 | 한 층이 아니라 전 층을 얇게 관통한다. 끝나면 **혼자서 시연·검증 가능**해야 한다 |
| 크기 | **새 컨텍스트 하나에 들어가는 분량**. 넘으면 쪼갠다 |
| 막는 것 | 시작 전에 반드시 끝나 있어야 하는 슬라이스를 적는다. 없으면 「없음」 |
| 선작업 | 구현을 쉽게 만드는 사전 정리(prefactor)가 있으면 **맨 앞 슬라이스**로 둔다 |

**작업 순서는 프론티어다** — 막는 것이 전부 끝난 슬라이스는 어느 것이든 집을 수 있다.
번호는 의존 순서지 강제 순서가 아니다.

### 예외: 광역 리팩토링은 수직으로 자르지 않는다

컬럼 개명·공유 타입 변경처럼 **한 번의 기계적 수정이 호출처 수천 곳을 동시에 깨뜨리는**
작업은 어떤 수직 슬라이스도 초록으로 착지할 수 없다. 억지로 트레이서 불릿에 밀어넣지 말고
**확장 → 이주 → 수축**으로 배열한다.

| 단계 | 내용 | 막는 것 |
| --- | --- | --- |
| ① 확장 | 새 형태를 **옛 형태 옆에** 추가한다 — 아무것도 깨지지 않는다 | 없음 |
| ② 이주 | 호출처를 폭발 반경 단위(패키지별·디렉토리별)로 옮긴다. 옛 형태가 남아 있으므로 배치마다 CI가 초록이다 | ① |
| ③ 수축 | 남은 호출처가 0이 된 뒤 옛 형태를 지운다 | ②의 모든 배치 |

배치조차 단독으로 초록일 수 없으면 순서는 유지하되 통합 브랜치를 공유하고,
**마지막 통합·검증 슬라이스에서만** 초록을 약속한다.
