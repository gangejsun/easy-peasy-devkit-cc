# /image-generator — 래스터 이미지 생성

## 경계 — 여기서 만들지 않는 것

**이 스킬은 래스터 원본만 담당한다.** 아래는 각각 더 잘하는 자리가 따로 있고,
그쪽이 만든 것은 편집·버전관리·diff가 되지만 래스터는 되지 않는다.

| 요청 | 여기가 아니라 |
| --- | --- |
| 아키텍처·플로우·시퀀스·ER·간트 등 도해 | `diagram-design` 플러그인 |
| 차트·그래프·대시보드 | `dataviz` (또는 코드로 렌더) |
| 디자인 시스템·색·타이포·화면 설계 | `ui-ux-design` |
| 기존 화면 캡처 | playwright (`ui-ux-design`의 `ui-probe.sh`) |
| 로고·아이콘 **세트의 확장** | 기존 SVG 체계를 잇는다 — 새로 그리면 세트가 깨진다 |

**단순 도형·괘선·단색 배지는 CSS·SVG로 만든다.** 생성 모델에 보내면 비용이 들고
결과가 매번 달라지며 수정이 불가능하다. 이 스킬은 **사진·질감·일러스트·목업처럼
코드로 만들 수 없는 것**에만 쓴다.

## Step 0 — 준비 판정 (3상태)

```bash
bash ${CLAUDE_SKILL_DIR}/scripts/image-gen.sh --probe
```

| 출력 | exit | 다음 |
| --- | --- | --- |
| `ready` | 0 | Step 1로 (API 경로 가능) |
| `no-key` | 2 | **차단하지 않는다** — Step 4 인계 모드로 간다 |
| `unavailable` | 2 | python3 부재. 마찬가지로 인계 모드로 간다 |

**판정 불가를 실패로 읽지 않는다.** 키가 없는 것은 정상 상태이고, 그때 할 일은
중단이 아니라 **사람이 만들 수 있는 프롬프트를 내주는 것**이다.

## Step 1 — 동의와 과금 고지 (API 경로를 쓸 때만)

`epcc.config.json`의 `assets.imageProvider`를 읽는다.

- `"openai"` → 동의가 이미 있다. 묻지 않고 Step 2로
- `"manual"` → 사용자가 직접 만들기로 했다. 묻지 않고 **Step 4 인계 모드**로
- 없거나 빈 값 → **한 번만 묻는다.** `AskUserQuestion`으로 아래를 그대로 보여준다

> **OpenAI Images API는 ChatGPT 구독과 별개로 과금됩니다.** 구독료는 API 사용량을
> 전혀 커버하지 않으며, 플랫폼 계정에 이미지 단위로 청구됩니다.
> 1024×1024 기준 추정: low 약 $0.006 · medium 약 $0.053 · high 약 $0.211
> (1536×1024·1024×1536은 medium $0.041 · high $0.165로 더 쌉니다.)

선택지는 둘이다 — 「API로 생성 (과금)」 · 「내가 직접 만들어 넣겠다 (무료)」.
**답을 `epcc.config.json`의 `assets.imageProvider`에 기록한다** (`openai` 또는 `manual`).
기록하지 않으면 매번 묻게 되고, 매번 묻는 장치는 꺼진다.

키는 **저장하지 않는다.** 환경변수 `OPENAI_API_KEY`만 쓴다 — `.env`·`epcc.config.json`·
셸 설정에 쓰지 않는다(이 하네스의 `security-check` 훅이 차단한다).

## Step 2 — 프롬프트 작성 (두 경로가 공유한다)

**이 단계가 결과를 정한다.** API로 보내든 사람이 ChatGPT에 붙여넣든 **같은 프롬프트**를 쓴다 —
그래서 정본이 하나이고, 경로가 갈리는 것은 Step 3뿐이다.

**순서를 지킨다: 장면·배경 → 주체 → 디테일 → 제약.** 이 순서가 아니면 모델이 주체를
배경으로 흡수한다.

1. **용도를 먼저 적는다** — "웹 히어로 배너", "앱 스토어 스크린샷", "블로그 삽화".
   용도가 완성도와 구도를 정한다. 빠뜨리면 모델이 일반적인 스톡 이미지를 낸다
2. **주체를 구체화한다** — 무엇이 화면의 몇 퍼센트를 차지하고 어디를 보는지까지
3. **사실적 사진이면 카메라 언어로 쓴다** — 렌즈(35mm·85mm), 조리개, 조명 방향, 시간대
4. **텍스트가 들어가면 정확히 인용부호로 감싸고 서체 계열·위치를 지정한다.**
   철자가 까다로우면 한 글자씩 끊어 적고 그대로 렌더하라고 요구한다
5. **제약을 마지막에 모은다** — 배경색, 여백, 넣지 말 것, 잘리면 안 되는 부분
6. **프로젝트에 디자인 시스템이 있으면 토큰을 주입한다** —
   `dev/docs/design/<project>/MASTER.md`의 색 hex와 타이포 방향을 프롬프트에 그대로 넣는다.
   넣지 않으면 산출물이 화면과 겉돈다
7. **이미 상세한 브리프는 늘리지 말고 정리만 한다.** 살을 붙이면 사용자의 의도가 묻힌다

**시크릿이 보이면 멈춘다.** 프롬프트에 키·토큰·내부 URL·실명 고객 데이터가 섞이면
그대로 외부로 나간다. 발견하면 진행하지 말고 사용자에게 알린다.

**프롬프트는 영어로 쓴다** — 이미지 모델의 학습 분포가 영어에 몰려 있어 같은 지시라도
영어가 더 정확히 반영된다. 사용자에게 설명하는 말은 사용자의 언어로 한다.

## Step 3 — 생성 (API 경로)

```bash
bash ${CLAUDE_SKILL_DIR}/scripts/image-gen.sh \
  --prompt "<Step 2의 프롬프트>" \
  --out <저장 경로> \
  --size 1024x1024 --quality medium --format png
```

- 치수 제약: `16의 배수` · 최대 변 3840 · 종횡비 3:1 이내 · 총 픽셀 655,360~8,294,400.
  **스크립트가 호출 전에 검증하므로** 잘못된 치수로 과금되지 않는다
- 초안은 `--quality low`로 뽑아 방향을 확인하고, 확정된 것만 `medium`·`high`로 다시 뽑는다.
  high는 low의 **35배**다 — 탐색 단계에 쓸 값이 아니다
- 프롬프트가 길면 `--prompt-file <파일>`을 쓴다 (셸 인용 사고를 피한다)

**Step 4 검증까지가 한 동작이다.** 스크립트는 파일 존재·0바이트 아님·포맷 시그니처를
확인하고, 응답의 `usage`를 **실측 그대로** 출력한다. 그 수치를 사용자에게 전달한다 —
"얼마 나왔을 것이다"가 아니라 "얼마 나왔다"를 말한다.

생성 후 **요청한 치수와 실제 치수를 대조한다.** 모델이 프롬프트를 재구성하면서 비율이
어긋날 수 있다. 어긋나면 사용자에게 알리고 다시 뽑을지 묻는다 — 조용히 넘기지 않는다.

## Step 4 — 인계 모드 (키가 없거나 사용자가 직접 만들 때)

**이것은 실패 경로가 아니라 정식 경로다.** 할 일은 "못 만든다"가 아니라
**사용자가 ChatGPT에 붙여넣으면 요청한 그 이미지가 나오는 프롬프트를 완성해 주는 것**이다.

`dev/docs/assets/<slug>.prompt.md`를 만든다. 네 덩어리로 구성한다:

```markdown
# <무엇을 만드는가>

## 붙여넣을 프롬프트
<Step 2에서 완성한 프롬프트 — 한 덩어리로, 설명 없이. 이대로 복사되는 부분이다>

## 규격
| 항목 | 값 |
| --- | --- |
| 치수 | 1024x1024 |
| 포맷 | PNG |
| 배경 | 흰색 불투명 |
| 용도 | <어디에 쓰이는가> |

## 저장 경로
`<프로젝트 내 정확한 경로>` — 이 이름 그대로 저장해 주세요.

## 마음에 안 들 때 이어서 보낼 말
- 더 단순하게: "Simplify: remove <X>, keep <Y> unchanged."
- 색만 바꾸기: "Same image, change only the <부위> color to <hex>."
- 구도만 바꾸기: "Same subject and style, reframe to <구도>."
```

**마지막 덩어리를 빼지 않는다.** 한 번에 원하는 것이 나오는 일은 드물고, 사람이 즉흥적으로
수정 요청을 쓰면 이전 결과의 좋았던 부분까지 함께 날아간다. 「한 번에 하나만 바꾸고
나머지는 유지하라」는 문장을 미리 쥐어 주는 것이 이 파일의 값어치다.

사용자에게는 **어디에 무엇을 넣으면 되는지**까지 말한다 — ChatGPT(또는 Codex 데스크톱 앱)에
프롬프트를 붙여넣고, 받은 이미지를 위 저장 경로에 두면 된다고.

파일이 도착하면 **규격을 검증한다** — 치수·포맷·0바이트 아님. 자동 생성 경로와 같은 기준이다.

## 한계 — 약속하지 않는 것

- **투명 배경**: API 문서상 `background=transparent`가 유효하지만 gpt-image-2의 실제 알파
  품질은 이 저장소에서 검증하지 않았다. 정확한 누끼가 필요하면 결과를 눈으로 확인한다
- **치수 결정론**: 모델이 프롬프트를 재구성하므로 요청 치수와 결과가 어긋날 수 있다
- **코덱스 경유는 불가**: 코덱스 CLI의 내장 `image_gen`은 데스크톱 앱 전용이다.
  `codex exec`·`codex app-server` 양쪽 도구 목록에 없음을 실측했다(2026-09) —
  그래서 이 스킬은 코덱스를 부르지 않고 API를 직접 부른다
