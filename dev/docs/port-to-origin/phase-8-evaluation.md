# Phase 8 — 7축 평가 스킬 + 되먹임 폐쇄 + 최종 검증

> `~/Documents/easy-peasy-claudecode-devkit`에서 붙여넣는다. **Phase 7의 DoD를 통과한 뒤에.**

---

9단계 중 **마지막**이다. 하네스가 **스스로를 평가하고 줄어들 수 있게** 만들고,
Phase 0의 기준선과 대조해 이번 개편이 실제로 무엇을 바꿨는지 확정한다.

## 왜 필요한가

개편은 끝나면 부패하기 시작한다. 그리고 **평가 자체가 틀릴 수 있다.**
출처 저장소의 v3 평가에서 **신규 결함 5건 중 4건이 계측기(doctor) 자신과 배포 경로에서
나왔다.** v1·v2가 "무엇을 재는가"를 개선하는 동안 "**재는 도구가 맞는가**"를 아무도 보지 않았다.
그중 하나는 전회 평가의 **오탐**이었다 — 파일 개수만 보고 코드를 열지 않아 이미 작동 중인
회전 로직을 "상한 없음"으로 판정했다.

그래서 이 스킬의 설계 원칙은 둘이다:

> **① 사실 측정은 doctor가 한다. 이 스킬은 그 출력을 입력으로 받아 판단만 한다.
> 다시 세지 않는다 — 다만 세는 방식은 봐야 한다.**
>
> **② 전회 판정을 계승하지 않는다. 반드시 현재 파일로 재확인한다.**

## 할 일

### 1. `.claude/skills/harness-evaluation/SKILL.md` 재작성

**자산 단위**("무엇이 있는가")가 아니라 **경로 단위**("작업 1건이 어떤 노드를 밟고,
어디서 멈추고, 무엇을 남기는가")로 평가한다. **점수를 내지 않는다** — 산출물은
**결함 목록**이고, 그 자체가 개선 백로그다.

#### 7축

**축 간 담당이 겹치면 결과가 애매해진다.** 각 축의 "만 본다"를 지킨다.

| 축 | 질문 | 기계 판정 (doctor) | 모델 판단 |
| --- | --- | --- | --- |
| **P1 라우팅·정본 일관성** | 같은 사실을 두 곳이 다르게 주장하지 않는가 | `--graph`의 Phase 어휘 대조 · `--fast`의 버전 스탬프·선언↔실물 | 위반이 실제 오동작을 만드는가 · 문서 의존성 6엣지 폐쇄 · 참조 신선도 4축 |
| **P2 발동 정확성** | ①조건 충족 시 발동 ②노드 권한 형태 ③잡아야 할 것을 잡는가 **④안 잡을 것을 안 잡는가** | 그래프 선언 대조 · 에이전트 frontmatter · `--self-test` 양성/무해 픽스처 | 수동이 의도인가 누락인가 · 게이트 미탐 · handoff 복원 충분성 · **오탐 이력**(`--lessons`의 `false-positive`) |
| **P3 루프 종료성** | 반복 노드가 상한·종료 술어를 갖는가 | 상한 grep — **`references/` 포함** | 상한이 작업 성격에 적정한가 |
| **P4 되먹임 폐쇄성** | 기록이 자산 diff로 돌아오는가 | `--lessons` 승격 후보 + `--graph`의 store 소비 경로 | 승격 형태 선택이 옳은가 · **수축이 일어나는가** |
| **P5 경로 비용** | 대표 작업 1건의 노드·게이트 수와 상주 비용이 적정한가 | `--usage`(상주 비용·graph.log·skilluse.log) | Reversible 경로의 과잉 게이트 · 상주 예산 배분 |
| **P6 구조 절제** | ①**과잉** ②**중복** ③**애매** | `--usage` 무호출 목록 · `--fast` 네이티브 문구·description 위생 · 잔존 경고 | 각 항목의 실질 판단 |
| **P7 경계** | ①밖으로 나가는가 ②남는가 ③출처가 있는가 | `--fast`의 platform-contract 180일 · 로그 회전 grep | 사전 고지 지점 실재 · 잔존물의 비밀정보 · 귀속 |

**P5와 P6은 직교한다** — 비용이 싸도 중복일 수 있고(안 쓰이는 스킬), 비싸도 정당할 수
있다(security-check). **P2와 P7도 직교한다** — P2는 차단력, P7은 경계 넘김.

#### P6 세부 — 이미 있는 자산에게 다시 던지는 3-질문

`harness-change.md`의 추가 전 3-질문은 **자산을 만들 때만** 걸린다.
존재하는 자산에게 그 질문을 다시 던지는 곳이 여기다. **없으면 하네스는 자라기만 한다.**

| 항목 | 무엇을 보는가 |
| --- | --- |
| ① **과잉** | 지금도 필요한가 · 모델 향상으로 불필요해지지 않았는가 · **문서 1~3줄로 될 것을 스크립트로 만들지 않았는가**(해결 수단 우선순위 역행) |
| ② **중복** | 커스텀 vs **네이티브**(`/code-review`·`/simplify`·`/security-review`·`skill-creator`·`/init`·`/run`·`/loop`) · 커스텀 vs 커스텀 · **같은 규범을 두 파일이 주장**(정본/인용 미표시) |
| ③ **애매** | 산출이 행동으로 이어지는가 — **꺼지지 않는 경고** · 판정 불가를 차단으로 접음 · **두 검사가 같은 것을 셈** · 조치 문구 없는 실패 보고 |

판정에는 **시점 스탬프**("Claude Code 버전 · 모델 · 날짜")를 반드시 남기고,
직전 스탬프가 **30일 이내면 재조사를 생략**한다.

**커스텀 폐기를 제안하려면 양쪽 본문을 실제로 열어** 커버 영역을 비교한다 —
**네이티브의 존재는 중복의 증거이지 열등의 증거가 아니다.**
비교 대상은 **훼손되지 않은 최선 버전**이어야 한다(과거 커밋이 내용을 삭감했을 수 있다).

#### 워크플로우

**Step 1 — 기계 판정 수집. 다시 세지 않는다.**

```bash
bash .claude/scripts/doctor.sh --all
grep -rln '최대 [0-9]회\|1회 재' .claude/skills/*/SKILL.md .claude/skills/*/references/*.md
grep -rln 'WebSearch\|WebFetch\|codex\|gemini' .claude/skills/*/SKILL.md .claude/agents/*.md
ls dev/handoff/ 2>/dev/null | wc -l
```

**반복 증거의 출처**: `docs/lessons.md` · `.claude/.epcc/{hookrun,graph,skilluse}.log` ·
`dev/handoff/*.md`. **2회 이상 관측된 것만 개입 근거가 된다** — 1회는 가설이지 패턴이 아니다.

**Step 2 — 7축 판정 + 결함 목록**

- 축마다 두 줄: `측정: <기계 출력 요약>` / `판정: <충족|부분 충족|미달|미계측> — <근거>`
- 결함 형식: `ID | 심각도 | 파일:행 | 실패 시나리오 | 개입 지점 | 수정 방향`
- 심각도는 `epcc-reviewer`와 동일 어휘 (Critical / Important / Suggestion)
- **개입 지점**은 수정이 놓일 자리다: ①시작 브리핑 ②결정 시점(규칙 `paths:`·스킬 발동)
  ③행동 체크포인트(PreToolUse) ④사후 복구(Stop·PostToolUse·handoff).
  **같은 실패라도 어느 지점에 놓느냐로 효과가 갈린다**
- **Critical은 재현으로 뒷받침돼야 한다** — 픽스처·실행으로 확인한 것만. 문서 독해만으로는 Important 이하
- **실패 시나리오를 쓸 수 없으면 그 결함은 보고하지 않는다** — "~일 수 있다"는 추측이다
- **grep·doctor에 걸리지 않은 문서를 읽으러 가지 않는다.** 전 문서 독해는 폐기된 방식이다
- **전회 판정을 계승하지 않는다**

**Step 3 — 저장 + 전회 대비 + 수축 제안**

`dev/docs/harness-evaluation/v<N>.md`에 저장한다. 반드시 포함:

| 절 | 내용 |
| --- | --- |
| 전회 대비 | 결함 수 변화(심각도별) · **신규** · **해소** · **철회(오탐)** · 상주 비용 변화 |
| **수축 제안** | `대상 \| 사유(과잉/중복/애매) \| 대체 경로 \| 회귀 위험`. **평가가 자산을 늘리기만 하면 실패다** |
| **미계측 항목 (정직 보고)** | 재지 못한 것을 **명시한다.** 침묵 생략은 "다 쟀다"로 읽힌다 |
| 전회 판정 철회 | 오탐으로 드러난 것. `docs/lessons.md`에 `[category: false-positive]`로도 기록 |

### 2. 되먹임 폐쇄 — store 처분 결정

Phase 5의 `--graph`가 **아웃바운드 엣지 없는 store**를 경고했을 것이다.
이 저장소에서 후보는 `dev/docs/insights/`(insight-saver) · `dev/docs/digital-twin/`(profile-update)다.

출처 저장소에서 이 결함(E-01)은 **v1→v2→v3 3회 연속 잔존**했다.
평가 문서의 판정이 이랬다:

> **3회 연속 잔존은 "고칠 생각이 없다"는 신호다 — 폐지 쪽을 먼저 검토한다.**

둘 중 하나를 **지금 결정한다**:

- (a) **소비 경로를 만든다** — `--lessons` 집계 대상을 확장하거나, 평가 스킬 Step 1의
  입력으로 넣는다. 그리고 그 엣지를 그래프에 선언한다
- (b) **폐지한다** — 쓰기 노드(스킬)를 `.claude/deprecated/`로, 저장소는 아카이브

**"나중에 정한다"는 (a)도 (b)도 아니다.** 읽는 노드가 없는 저장소는 비용만 있고
드리프트의 원천이다.

### 3. 30일 재평가 알림

**단, 이 알림이 꺼지지 않는 경고가 되지 않게 한다.** 알림은 평가를 실행하면 사라져야 하고,

않도록, **주기 조건부 엣지는 죽은 엣지 판정에서 제외**한다.

### 5. 마지막 확인 — 규칙이 실제로 도달하는가

> **출처 저장소가 4개월간 놓친 것이 정확히 이 한 가지다.**

새 세션을 열고 **모델에게 직접 확인시킨다**:

1. 아무 파일도 열기 전 — T0 되돌림 분류표와 Phase 라우팅 표가 컨텍스트에 있는가
2. `src/` 파일을 읽은 뒤 — `code-change.md`·`security.md`·`reversibility.md`가 떴는가
3. `supabase/migrations/` 파일을 읽은 뒤 — `data-modeling.md`가 떴는가
4. 실제로 `packages/shared/`를 수정하려 할 때 — **Costly 판정과 `epcc-reviewer` 요구가 발동하는가**
5. 소스를 고치고 빌드 없이 종료하려 할 때 — `build-gate`가 차단하는가

**5개 중 하나라도 실패하면 개편은 끝나지 않았다.** 자산이 존재하는 것과 도달하는 것은 다르다.

## 하지 말 것

- **점수를 내지 않는다.** 산출은 결함 목록이다
- **doctor 출력을 그대로 옮겨 적지 않는다.** 판단을 적는다. 다만 **세는 방식은 본다** —
  출처의 신규 결함 4건 중 3건은 doctor 출력을 **믿지 않고 읽었을 때만** 나왔다
- 전회 결함을 재확인 없이 계승하지 않는다
- **수축 제안 없이 평가를 끝내지 않는다.** 늘어나기만 하는 평가는 하네스를 비대하게 만든다
- 미계측 항목을 침묵으로 생략하지 않는다
- **꺼지지 않는 경고를 만들지 않는다**

## 완료 기준 (DoD)

1. `.claude/skills/harness-evaluation/SKILL.md`가 7축·워크플로우 3단계·보고 형식을 담고,
   **description에 "사실 측정은 doctor가 한다"가 명시**돼 있다
2. `dev/docs/harness-evaluation/v1.md`가 생성됐고 7축 판정·결함 목록·**수축 제안**·
   **미계측 항목**·**Phase 0 대조표**를 전부 담는다
3. 아웃바운드 없는 store 2건의 처분이 **(a) 소비 경로 신설 또는 (b) 폐지로 결정**되고
   그래프에 반영됐다
4. `doctor --all` 실패 0 · `guide-gate --regress` 실패 0 · `pack-smoke --self-test` 실패 0
5. **「마지막 확인」 5항목이 전부 실제 세션에서 통과**했고 그 결과가 리포트에 있다
6. Phase 0에서 "조용히 무시되는 중"이던 훅이 **0건**이다
7. `.claude/deprecated/`의 만료 항목이 `--lessons`에 보고되고, 만료된 것은 처분됐다
