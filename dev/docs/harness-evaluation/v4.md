## 설치본 교체 — 이번 회차가 상태를 바꿨다

평가 착수 시 `Skill(epcc-devkit:harness-evaluation)`이 **캐시 2.0.0의 폐기된 10축 SKILL.md**를
로드했다(E-08의 3회째 재현). 사용자 결정으로 릴리스 절차 대신 **로컬 마켓플레이스**로 실물 설치했다:

```
claude plugin validate .                      → ✔ (단, 검사 대상은 marketplace.json뿐 — E-16)
claude plugin marketplace remove easy-peasy-devkit    # git 소스(=origin/main=2.0.0) 등록 해제
claude plugin marketplace add /Users/gyeong/Documents/easy-peasy-devkit-cc
claude plugin install epcc-devkit@easy-peasy-devkit
```

(`installed_plugins.json`의 `gitCommitSha`는 `bacaa9a`로 기록되나 내용은 워킹트리다. 이 sha는
디렉토리 소스에서 **내용을 서술하지 않는다**). 캐시는 심볼릭이 아니라 **사본**이므로 이후 워킹트리
