## EPCC 운영 규칙

**되돌림 분류** — 경로로 판정한다. 규모(줄 수·파일 수)로 판단하지 않는다. 검증 강도와 **실행자**를 이 표가 정한다.

| 클래스 | 판정 경로 | 요구 — 누가 하는가 |
| --- | --- | --- |
| Irreversible | `**/migrations/**` · auth/RLS · 결제·정산 · 운영 데이터 | `epcc-reviewer` 다관점 팬아웃 + **사용자 확인** + 롤백 절차 |
| Costly | 공유 패키지 · public API · 타입 계약 · `**/api/**` · `**/actions.ts` · `**/middleware.ts` · 생성 파일 | `epcc-reviewer` 필수 — **자기 리뷰로 대체하지 않는다** |
| Reversible | 그 외 전부, 테스트 코드 포함 (기본값) | 바로 진행. 마무리 문서화는 `/completion-review` |

**작업 진입** — 아래 넷이 모두 충족되면 준비 작업 없이 바로 구현한다.
의도 명확 · 컨텍스트 최신 · 영향 반경 파악 · 검증 경로 존재.
미충족 항목만 채운다 — 충족된 항목을 위한 문서를 만들지 않는다.
**2개 이상 미충족이거나 영향 반경이 불명확하면 `epcc-planner` 서브에이전트에 진단을 위임한다.**
넷 중 셋은 스스로 해결한다 — **의도만은 사용자에게 있다.** 의도 명확이 미충족이면 미충족 개수와 무관하게 묻는다.
무엇을 어떤 순서로 만드는지(Phase)는 `.claude/rules/workflow-routing.md`의 라우팅 표가 정한다(매 세션 상시 로드).

**최소 수정** — 요청된 것만 구현한다. 범위 밖 파일 수정이 필요하면 멈추고 확인한다.
리팩토링·추상화·의존성 추가는 별도 요청 없이 하지 않는다.
"나중에 필요할 수 있으니"는 근거가 아니다.
고치는 파일 **안에서도** 요청과 무관한 주석·서식·스타일은 그대로 둔다 — 남의 데드코드는 보고만, 내 변경이 만든 고아만 치운다.

**검증** — 소스를 고쳤으면 빌드/테스트까지가 한 동작이다. "작성했다"는 "작동한다"가 아니다.
스크립트·훅을 추가·수정하면 실제 실행 → exit 0 확인 → 예상 출력 확인까지 수행한다.

**분기점** — 결정의 결과가 되돌리기 어렵거나 사용자 워크플로우에 영향을 주면,
선택지와 **선택 간 실질 차이**를 제시하고 사용자가 고르게 한다.
**방법**에 대한 사소한 결정은 스스로 정하고 진행한다 — 매 결정마다 묻지 않는다.

**컨텍스트 경계** — 국면(설계·구현·QA)이 **끝날 때** 정한다. 국면 중간에는 결정하지 않는다 — 계속하거나 남은 일만 서브에이전트로 쪼갠다.
위에서부터 첫 「예」가 답이다. ① 다음 국면이 이 대화를 **1차 출처**로 쓰거나 창에 여유가 충분한가 → **계속**
② 지금 맥락이 다음 국면과 무관한가 → `/clear` ③ 다른 도구·디렉토리·사람에게 넘기는가 → **핸드오프**
④ 감독 없이 끝낼 수 있는가 → **서브에이전트** ⑤ 그 외 → `/compact` + 다음에 할 일을 함께 지시.
**①을 가장 먼저 배제한다** — 나머지 넷은 전부 1차 출처를 요약본으로 바꾸고, 그 손실은 되돌릴 수 없다.

**교훈** — 사용자가 코드·접근·워크플로우를 지적하면 **경로와 무관하게** 그 즉시 `docs/lessons.md`에 기록한다 (형식은 `.claude/rules/lessons.md`).
**언어** — 내부 추론·분석은 영어. 사용자 출력과 산출 문서 산문은 {{RESPONSE_LANGUAGE}}로, 직역이 아니라 의도·문맥·도메인을 반영해 그 언어 사용자가 자연스럽게 읽도록 쓴다. 코드·식별자·명령·기계 판독 토큰과 **영어로 통용되는 전문용어**(Bottom Sheet · GNB · middleware · migration)는 번역하지 않는다.
